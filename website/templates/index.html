PHTGC FlightTracker

Personal project that tracks a small fleet of aircraft using an ADS-B receiver. An ADS-B feeder (adsb.im / ultrafeeder) streams transponder messages over SBS TCP, which are forwarded here and stored in a SQLite database. The altitude graph updates every 5 seconds.

StackPython · Flask · Chart.js · SQLite · Docker · Traefik
Sourcegithub.com/digitalica/flighttracker

How to use the graph
Click the aircraft registration (chart title) to pick a different aircraft.
Click the Y-axis label to toggle barometric ↔ AGL altitude.
Click the X-axis label to cycle through time ranges (30 min → 16 h).
Red-shaded bands indicate periods without ADS-B reception (> 60 s gap).
