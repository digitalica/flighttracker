PHTGC FlightTracker

Personal project that tracks the PH-TGC (and for testing some other EHHV based aircraft) using an ADS-B receiver. The goal is to quickly and reliably see the altitude of PH-TGC. And have more accurate information at Skydive Hilversum.

The altitude graph updates every 5 seconds. The Event page does too, and will use voice to announce events like takeoff, reaching altitude and landing.

The source is an ADS-B feeder (adsb.im / ultrafeeder) located at EHHV, that also feeds to https://globe.adsbexchange.com (so that will have more accurate information around EHHV too)

StackPython · Flask · Chart.js · SQLite · Docker
Sourcegithub.com/digitalica/flighttracker

How to use the graph
Click the aircraft registration (chart title) to pick a different aircraft.
Click the Y-axis label to toggle barometric ↔ AGL altitude.
Click the X-axis label to cycle through time ranges (30 min → 16 h).
Red-shaded bands indicate periods without ADS-B reception (> 60 s gap).
